# UESPL Website

A modern and fully responsive website built using React.js and Vite for UESPL. The project showcases the company's services, projects, team members, and company information through a clean and user-friendly interface.

## Features

- Responsive design for Desktop, Tablet, and Mobile devices
- Modern React component architecture
- Project showcase section
- Services section
- About Us page
- Team section
- Contact section
- Image galleries and sliders
- Clean UI with reusable components
- Optimized performance with Vite

## Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3
- React Router DOM

## Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project folder:

```bash
cd UESPL-Project
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
